# Program 6: MQTT publisher and Flask dashboard

Simplified learning version based on the supplied IoT lab manual.

## Run
1. Start `python app.py` in one terminal.
2. Start `python publisher.py` in another terminal.
3. Visit http://127.0.0.1:5000 and refresh.

Learning simplification: local in-memory dashboard, not Supabase. Uses public broker; use unique topic for personal testing.
