# Program 16: Temperature prediction with linear regression

Simplified learning version based on the supplied IoT lab manual.

## Run
1. Download Beijing Multi-Site Air Quality dataset from UCI (link below).
2. Copy one station CSV into this folder and rename it station.csv.
3. Run `python temperature_model.py`.

Dataset: https://archive.ics.uci.edu/dataset/501/beijing . This is a simplified random train/test split, not a time-aware evaluation.
