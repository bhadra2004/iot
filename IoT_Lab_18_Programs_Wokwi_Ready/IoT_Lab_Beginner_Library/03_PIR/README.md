# Program 3: ESP32 motion detection

Simplified learning version based on the supplied IoT lab manual.

## Run
1. Connect PIR OUT to GPIO27 and sensor power/GND as specified for your module.
2. Upload PIR/PIR.ino and open 115200 Serial Monitor.
3. Allow PIR warm-up time, then move in front of sensor.



### Wokwi simulator
Open the Arduino sketch folder in this program, and copy its `.ino`, `diagram.json` and `libraries.txt` contents into a Wokwi ESP32 project. See the root `WOKWI_SETUP.md`.
