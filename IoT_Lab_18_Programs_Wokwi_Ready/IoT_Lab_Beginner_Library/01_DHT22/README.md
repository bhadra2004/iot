# Program 1: ESP32 DHT22 sensor

Simplified learning version based on the supplied IoT lab manual.

## Run
1. Install ESP32 board and DHT sensor library in Arduino IDE.
2. Wire DHT22 VCC to 3.3V, GND to GND and DATA to GPIO4 (use pull-up if bare sensor).
3. Open DHT22/DHT22.ino, choose ESP32 board and port, upload.
4. Open Serial Monitor at 115200 baud.



### Wokwi simulator
Open the Arduino sketch folder in this program, and copy its `.ino`, `diagram.json` and `libraries.txt` contents into a Wokwi ESP32 project. See the root `WOKWI_SETUP.md`.
