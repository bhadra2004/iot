# Program 17: Air quality category classification

Simplified learning version based on the supplied IoT lab manual.

## Run
1. Download the Kaggle India Air Quality Data dataset (link below).
2. Place city_day.csv in this folder.
3. Run `python air_quality_model.py`.

Dataset: https://www.kaggle.com/datasets/rohanrao/air-quality-data-in-india . The file is not included in this ZIP; obtain it from Kaggle.
