# Program 5: HTTP REST API and local dashboard

Simplified learning version based on the supplied IoT lab manual.

## Run
1. Run `python app.py` in one terminal.
2. Run `python sender.py` in another terminal.
3. Open http://127.0.0.1:5000 in a browser.

Learning simplification: stores readings in memory instead of Supabase. Restarting server clears data; original manual uses a cloud database.
