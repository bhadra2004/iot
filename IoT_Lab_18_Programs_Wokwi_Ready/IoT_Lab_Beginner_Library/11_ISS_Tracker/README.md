# Program 11: ISS tracking with CSV and graphs

Simplified learning version based on the supplied IoT lab manual.

## Run
1. Requires internet and the ISS API to be reachable.
2. Run `python iss_tracker.py`.
3. Observe CSV and plotted location readings.

Uses 10 readings to keep the first run short; set range(100) for manual requirement of 100 records.
