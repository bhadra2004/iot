# Program 15: Room occupancy decision tree

Simplified learning version based on the supplied IoT lab manual.

## Run
1. Download the UCI Occupancy Detection dataset (link below).
2. Extract datatraining.txt into this folder.
3. Run `python occupancy.py`.

Dataset: https://archive.ics.uci.edu/dataset/357/occupancy%2Bdetection . scikit-learn may warn about feature names for the sample prediction.
