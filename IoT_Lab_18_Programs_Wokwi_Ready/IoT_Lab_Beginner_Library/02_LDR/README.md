# Program 2: ESP32 light sensing

Simplified learning version based on the supplied IoT lab manual.

## Run
1. Connect LDR module analog output to GPIO34, power and GND appropriately.
2. Upload LDR/LDR.ino using Arduino IDE.
3. Read values in Serial Monitor (115200); thresholds depend on module and lighting.



### Wokwi simulator
Open the Arduino sketch folder in this program, and copy its `.ino`, `diagram.json` and `libraries.txt` contents into a Wokwi ESP32 project. See the root `WOKWI_SETUP.md`.
